# Force-Directed Graph Visualization
Using Vis.js Network for rendering interactive graph node structures in Streamlit HTML components.
## Features
* Node coloring by PARA category
* Dynamic edge thickness based on similarity score
* Hover tooltips with note summaries and body excerpts
* Drag, zoom, and physics solver stabilization
